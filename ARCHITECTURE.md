# Архитектура

Вход: URL сайта + бриф. Выход: XLSX для Директ Коммандера + чеклист
(режим campaign), SEO-отчёт (seo), медиапрогноз (forecast).

## Конвейер

```
URL, бриф
   │
   ▼
crawler.py ──► карточка бизнеса: бренд, категории, УТП, контакты
   │
   ▼
semantics.py ─► группы (бриф + категории), фразы (Wordstat или шаблоны),
   │            операторы +, кросс-минусация, минус-слова кампании
   ▼
ads.py ───────► тексты по правилам Директа: h1≤56, h2≤30, text≤81
   │            (подсчёт длины 1-в-1 с формулами Коммандера),
   │            комбинаторика 7 заголовков + 3 текста, быстрые ссылки,
   │            уточнения, UTM с плейсхолдерами
   ▼
builder.py ───► копия эталонного шаблона Коммандера, шапка кампании,
   │            данные с 16-й строки, эталонные формулы длины
   ▼
validator.py ─► перечитывает ГОТОВЫЙ файл целиком: ERR = блокер
   │
   ▼
campaign.py ──► XLSX + чеклист настроек
```

Wordstat (`wordstat.py`, Yandex Search API) — опциональный источник фраз:
платный API, без ключа конвейер работает на встроенных шаблонах.

## Интерфейсы (тонкие обёртки над одним ядром)

| Интерфейс | Модуль | Назначение |
|---|---|---|
| CLI | `app/cli.py` | полный набор: generate / seo / forecast / evaluate / validate |
| Telegram-бот | `app/bot.py` + `app/ui.py` | основной демо-сценарий, файлы в чат |
| Веб | `app/web.py` (FastAPI) | форма + живой прогресс, доступ по ключу `?key=` |

## Структура репозитория

```
├── README.md        запуск, метрики, декларация ИИ
├── ARCHITECTURE.md  этот файл
├── app/             код продукта (краулер → валидатор, см. конвейер)
├── tests/           74 офлайн-теста unittest, без сети
├── scripts/         benchmark.py — бенчмарк на реальных сайтах
├── templates/       эталонная выгрузка Коммандера (эталон для метрик)
└── output/          результаты генерации (в git не идут)
```

## Качество и метрики

`app/metrics.py` + `python -m app.cli evaluate` считают против боевого
эталона (templates/example_duplex_tgo.xlsx): Precision / Recall / F1,
покрытие спроса (взвешено частотами Wordstat), технический STP по логу
output/runs.jsonl, экономический эффект (допущения параметризованы).

## Безопасность

Секреты только через переменные окружения (`.env.example` как шаблон):
ключи Wordstat, токен бота, ключ веб-доступа. В коде и истории коммитов
ключей нет; история проверена поиском по паттернам.

## Развёртывание

Systemd-юниты `hse-direct-bot.service` (бот) и `hse-direct-web.service`
(веб, порт 8000). Достаточно 1 vCPU / 1 ГБ RAM, без GPU; генерация
кампании 5–10 с.
