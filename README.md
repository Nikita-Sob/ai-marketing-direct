# Генератор маркетинга на ИИ: кампания Директа, SEO-отчёт, медиапрогноз

Учебный проект НИУ ВШЭ, курс «ИИ в маркетинге и коммуникациях».

Вход: ссылка на сайт + бриф. Выход (3 режима на одном ядре):
- 🚀 **Кампания Яндекс Директа (ТГО)**: XLSX для Директ Коммандера + чеклист настроек
- 🔍 **SEO-отчёт**: семантическое ядро с частотами, gap-анализ, контент-план, meta-теги
- 💰 **Медиапрогноз**: показы, клики, бюджет по модели с явными допущениями

Ядро: краулер → семантика (Wordstat или встроенная модель) → генерация текстов
по правилам Директа (лимиты 56/30/81, подсчёт длины 1-в-1 как в Коммандере) →
валидатор каждой строки → сборка XLSX по эталонному шаблону.

## Быстрый старт (бесплатный режим, без внешних API)

    python3 -m venv .venv
    .venv/bin/pip install -r requirements.txt
    cp .env.example .env        # заполнять необязательно: всё работает и без ключей
    .venv/bin/python -m unittest discover tests          # ~70 тестов, без сети
    .venv/bin/python -m app.cli generate https://duplex-shop.ru --brief "рации для охоты" --no-wordstat
    .venv/bin/python -m app.cli seo https://kuppersberg.ru --brief "встраиваемая техника" --no-wordstat

Результат: `output/*.xlsx` + чеклист. Без Wordstat семантика собирается на
встроенных шаблонах (оператор + на стоп-словах, кросс-минусация групп).
Опции CLI: `--region "Москва и область"`, `--max-groups 8`, `--no-wordstat`;
`validate --h1 ... --text ...` — проверка одного объявления,
`validate-xlsx file.xlsx` — проверка готового файла Коммандера.

## Wordstat (опционально)

Живые частоты запросов через Yandex Search API. API платный, поэтому по
умолчанию выключен и не требуется: ключи в env (YANDEX_SEARCH_API_KEY,
YANDEX_FOLDER_ID), любой режим падает на бесплатный, если ключей нет.
С ключом: фразы берутся из реальных запросов за 30 дней (Wordstat
topRequests), частоты идут в SEO-отчёт и прогноз.

## Как это работает

1. **Краулер** (app/crawler.py): главная страница → карточка бизнеса:
   бренд, категории каталога, УТП, телефон.
2. **Семантика** (app/semantics.py): группы = бриф + категории. Фразы из
   Wordstat (топ реальных запросов с фильтром информационного мусора),
   резерв из шаблонов. Оператор + на стоп-словах, кросс-минусация,
   автотаргетинг первой фразой.
3. **Объявления** (app/ads.py): шаблоны и правила в коде. Заголовки 56/30,
   текст 81, быстрые ссылки 4-8, комбинаторика по умолчанию
   (7 заголовков + 3 текста на объявление; отключается «без комбо»), уточнения,
   UTM с плейсхолдерами Коммандера.
4. **Сборка** (app/builder.py): копия эталонного шаблона Коммандера,
   шапка кампании, данные с 16-й строки, формулы длины идентичны
   эталонным (LEN без ! , . ; : кавычек, кавычка экранируется четырьмя).
5. **Валидация** (app/validator.py): подсчёт длины 1-в-1 как Коммандер,
   готовый файл перечитывается и проверяется весь, ERR = блокер.

## Три интерфейса

    # CLI (полный набор)
    .venv/bin/python -m app.cli generate|seo|forecast|evaluate|validate|validate-xlsx --help

    # Telegram-бот: токен у @BotFather (бесплатно), кладём в env HSE_BOT_TOKEN
    .venv/bin/python -m app.bot

    # Веб: .venv/bin/uvicorn app.web:app --port 8000, доступ по ?key=$WEB_TOKEN

Бот: меню на инлайн-кнопках, пошаговый диалог (сайт → бриф → регион),
живой прогресс, файлы с осмысленными именами. Сообщением одной строкой тоже
работает: `кампания: https://duplex-shop.ru | рации для охоты`.

Прод на сервере: systemd-юниты `hse-direct-bot.service` и
`hse-direct-web.service` (пример юнита в ARCHITECTURE.md).

## Оценка качества (метрики для защиты)

    .venv/bin/python -m app.cli evaluate

Считает и пишет в `output/evaluation_report.md`:
- **Точность / полнота / F1** против эталона: реальной кампании, собранной
  специалистом (templates/example_duplex_tgo.xlsx, выгрузка Коммандера)
- **Покрытие спроса**: полнота, взвешенная спросом эталонных фраз
- **STP** (Straight-Through Processing): доля прогонов от ссылки до файла
  без ручных правок (лог output/runs.jsonl)
- **Экономический эффект**: медиа-эффект покрытия, экономия труда, ROI, FTE;
  все допущения параметризованы (app/metrics.py) и печатаются

## Структура

    app/crawler.py     обход сайта, карточка бизнеса
    app/semantics.py   группы, фразы, операторы +, минус-слова
    app/wordstat.py    Yandex Search API (опционально)
    app/ads.py         тексты по правилам Директа, лимиты
    app/validator.py   лимиты 1-в-1 как в Коммандере, ERR/WARN
    app/builder.py     сборка XLSX по эталонному шаблону
    app/campaign.py    конвейер кампании + чеклист
    app/seo.py         SEO-отчёт
    app/forecast.py    медиапрогноз
    app/metrics.py     F1, STP, экономика
    app/bot.py, ui.py  Telegram-бот
    app/web.py         веб-интерфейс (FastAPI)
    app/cli.py         командная строка
    tests/             ~70 unittest-тестов, без сети
    templates/         эталонная выгрузка Коммандера
    output/            результаты генерации (в git не идут)

## Данные и принципы подготовки

- Источник данных о сайте: открытая главная страница (HTML, без JS),
  извлекаются категории, УТП, контакты
- Источник семантики: Wordstat (реальные запросы, 30 дней) или встроенные
  шаблоны фраз; информационный мусор (как выбрать, рейтинг, своими руками)
  фильтруется и уходит в минус-слова кампании
- Эталон для метрик: боевая выгрузка кампании Дуплекс Шоп из Коммандера
- Секреты только через env (.env.example), в репозитории и истории коммитов
  ключей нет

## Декларация использования ИИ при разработке

Часть кода написана с помощью ИИ-ассистента (Hermes Agent) по ТЗ и под
руководством команды: постановка задач, приёмка результатов, ревью,
тестирование на реальных данных (сайты kuppersberg.ru и duplex-shop.ru,
реальная выгрузка Коммандера) и продуктовые решения выполнены командой
проекта. Архитектура, правила Директа, формулы метрик и экономической
модели определены командой; ассистент использовался как инструмент
кодирования, аналогично IDE-ассистентам.
