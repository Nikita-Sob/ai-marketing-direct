# Генератор рекламных кампаний Яндекс Директа (учебный проект ВШЭ)

Курс «ИИ в маркетинге и коммуникациях», магистратура НИУ ВШЭ.
Вход: URL сайта и бриф. Выход: XLSX для Директ Коммандера (ТГО на поиске)
и чеклист настроек кампании.

## Запуск

    .venv/bin/python -m app.cli generate https://kuppersberg.ru --brief "встраиваемая техника"

Опции:
- `--region "Москва и область"` регион, имена с листа "Регионы" шаблона
- `--max-groups 8` сколько групп генерировать
- `--no-wordstat` не ходить в Wordstat (шаблонные фразы)

Другие команды:
- `validate --h1 "..." --h2 "..." --text "..."` проверка одного объявления
- `validate-xlsx file.xlsx` проверка готового файла Коммандера

Ключи Wordstat читаются из env: YANDEX_SEARCH_API_KEY, YANDEX_FOLDER_ID
(лежат в /root/.hermes/.env, в код и git не попадают).

## Как это работает

1. **Краулер** (app/crawler.py): главная страница сайта -> карточка бизнеса:
   бренд, категории каталога, УТП (гарантия/доставка/сервис), телефон.
2. **Семантика** (app/semantics.py): группы = категории + бриф. Фразы из
   Wordstat (Yandex Search API, топ реальных запросов с фильтром
   информационного мусора), резерв из шаблонов. Оператор + на стоп-словах,
   кросс-минусация групп, автотаргетинг первой фразой.
3. **Объявления** (app/ads.py): шаблоны и правила в коде (решение от 15.11,
   LLM-хук опционален). Заголовки 56/30, текст 81, быстрые ссылки 4-8,
   комбинаторика 7 заголовков + 3 текста, уточнения, UTM с плейсхолдерами.
4. **Сборка** (app/builder.py): копия эталонного шаблона Коммандера,
   шапка кампании (строки 6-13), данные с 16-й строки, формулы длины
   идентичны эталонным (LEN без ! , . ; : кавычки, кавычка экранируется
   четырьмя кавычками). Листы "Регионы" и "Словарь" не трогаем.
5. **Валидация** (app/validator.py): подсчёт длины 1-в-1 как Коммандер,
   все строки готового файла перечитываются и проверяются, ERR = блокер.

## Telegram

Отдельный бот: @HSE_Ya_Direct_bot (токен в /root/.hermes/.env как
HSE_BOT_TOKEN, в код и git не попадает). Работает как systemd-сервис:

    systemctl status hse-direct-bot
    systemctl restart hse-direct-bot
    journalctl -u hse-direct-bot -f

Формат сообщения боту:

    кампания: https://duplex-shop.ru | рации для охоты
    кампания: https://kuppersberg.ru | встраиваемая техника | Москва и область

Слово «комбо» в сообщении включает комбинаторику (по умолчанию выключена,
Коммандер пока капризничает на строках вариантов "+"). Ответ: XLSX для
Коммандера + чеклист настроек. Код: app/bot.py, тесты парсера в tests/.

## Демо

- Сайты: kuppersberg.ru, duplex-shop.ru (эталонная выгрузка от этого клиента
  лежит в templates/, можно сравнить сгенерированное с реальным).
- Сценарий: сообщение в бота -> файл через ~10 секунд -> показать чеклист
  и строку в XLSX (формулы длины, быстрые ссылки, комбинаторика).
- Тесты: `.venv/bin/python -m unittest discover tests` (29 тестов, офлайн).

## Структура

```
app/          краулер, семантика, wordstat, объявления, сборка, валидатор, CLI
templates/    эталонный XLSX Коммандера
tests/        unittest, без сети
output/       готовые кампании + чеклисты
.venv/        openpyxl, requests, bs4
```
