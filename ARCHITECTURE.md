# Архитектура проекта «Директ-генератор» (ИИ в маркетинге, ВШЭ)

Дата: 12.11.2026. Срок: 7 дней. Код пишет Никита, презентацию команда.

## Что это
Продукт: на вход URL сайта и бриф, на выход XLSX для Директ Коммандера (ТГО на поиске)
и чеклист настроек кампании.

## Где живёт код
Отдельный проект: `/root/projects/hse-education/ai-marketing-direct/`
(не внутри STORE77 и не внутри учёбы, чтобы не путать с рабочим кодом).

```
/root/projects/hse-education/ai-marketing-direct/
├── README.md                 # описание, запуск, метрики
├── PLAN.md                   # план на 7 дней, статусы
├── config.yaml               # ключи берём из env, не храним в коде
├── app/                      # код продукта
│   ├── crawler.py            # обход сайта, карточка бизнеса
│   ├── semantics.py          # ключи, кластеризация, минус-слова
│   ├── wordstat.py           # Yandex Search API (GetTop/GetDynamics)
│   ├── ads.py                # генерация объявлений + проверка лимитов
│   ├── builder.py            # сборка XLSX по шаблону Коммандера
│   ├── validator.py          # лимиты 56/81 симв, слова, знаки, структура
│   └── cli.py                # CLI: python -m app.cli <url> --brief ...
├── templates/                # эталонный XLSX Коммандера (от Никиты)
├── output/                   # готовые файлы кампаний
├── tests/                    # тесты на валидатор и сборку
└── demo/                     # материалы для демо
```

## Секреты
- Ключи Wordstat/Директа не в чат и не в git: кладём в `/root/.hermes/.env`
  (переменные `YANDEX_SEARCH_API_KEY`, `YANDEX_FOLDER_ID`), код читает из env.

## Интерфейс MVP: варианты и выбор

| Вариант | Плюсы | Минусы |
|---|---|---|
| Telegram-бот | уже есть инфраструктура, демо с телефона, живо | ограничен форматом сообщений, файл присылать можно |
| Веб-страница (Flask/FastAPI, 1 форма) | красивое демо: форма + кнопка «Скачать XLSX» | нужен хостинг/порт и дизайн |
| CLI | проще всего, ноль инфраструктуры | выглядит не как продукт |
| **Гибрид (выбрано)** | CLI внутри + Telegram-бот снаружи | - |

Решение: ядро — Python-модуль с CLI. Сверху тонкий Telegram-бот: прислал ссылку и бриф,
получил файл и чеклист. Для презентации запись экрана с бот + показать CLI.
Веб-версию делаем только если останется время (день 6-7).

## Этапы (7 дней)
- День 1: скелет репозитория, валидатор лимитов, каркас CLI.
- День 2: краулер (Kuppersberg), карточка бизнеса.
- День 3: семантика + группировка + минус-слова; wordstat.py когда будет ключ.
- День 4: генератор объявлений + цикл проверки/переписывания.
- День 5: сборка XLSX, проверка Никитой в Коммандере, правки.
- День 6: Duplex Shop, метрики, слепое сравнение.
- День 7: README, демо-сценарий, поддержка презентации.

## Что нужно от Никиты
1. Ключ Wordstat: каталог Yandex Cloud + сервисный аккаунт + API-ключ с областью
   `yc.search-api.execute`. Положить в env на сервере (покажу команды).
2. Выгрузка ТГО из Коммандера (пустой шаблон XLSX): файлом в чат.
3. 30 минут на проверку загрузки в Коммандер на день 5.
